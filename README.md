# Sync Them Lips
A Blender Add-On to allow users to add in voicelines and automate the lipsyncing process for 2D facial rigs in Blender.

# Video Demonstration
[Automate Lip-Syncing | My FREE Blender Add-on](https://youtu.be/oSr1VXfAI1g)

# How to Use
1. Download SyncThemLips.zip OR download the SyncThemLipsCode Folder and zip it
2. Open Blender -> Click Edit -> Preferences -> Add-ons -> Install from Disk -> Select Sync Them Lips Zip Folder
3. Select your armature/bone you want to audio sync
4. Enter Pose Mode (THIS ONLY WORKS IN POSE MODE)
5. Press 'N' for side panel
6. On the right hand side, you should be able to see SyncThemLips
![Sync Them Lips Side Panel](/ReadMe%20Images/Sync%20Them%20Lips%20Side%20Panel.png)

7. Adjust your settings and click Sync Them Lips. A window will pop up, and select all the voicelines you need.
![Sync Them Lips Selecting Audio](/ReadMe%20Images/Sync%20Them%20Lips%20Picking%20Audio.png)

8. You'll get your results and can see it in the non-linear animation window. You can also view your audio files in the sequencer if you added that.
![Sync Them Lips Results](/ReadMe%20Images/Sync%20Them%20Lips%20Results.png)

9. You can edit the results per action. Just open a graph editor and modify as needed!
![Sync Them Lips Edit Results](/ReadMe%20Images/Sync%20Them%20Lips%20Edit%20Results.png)

10. Additionally if you don't like your results, you can also clear all the voiceline actions the plugin created. These should be specifically tagged that they were created by this plugin so it should only delete these actions and voicelines.
![Sync Them Lips Clear Voicelines](/ReadMe%20Images/Sync%20Them%20Lips%20Clear%20Voicelines.png)
